# 🔫 Projeto Valorant

Uma página com os agentes do jogo Valorant e as informações deles. Com foco na prática de múltiplas tecnologias.

## 💻 Sobre o Projeto

Esse projeto foi desenvolvido para clonar a interface do site oficial do jogo Valorant, especificamente na aba de agentes. Com foco na prática de múltiplas tecnologias: Axios, CSS Modules, Context API, Typescript, Vitest e RTL, Framer Motion e React Router. 

## ✨ Funcionalidades

- Requisição dos agentes
- Página para cada agente com nome, descrição, habilidade e imagem.
- Footer e Header estilizados como o original
- Responsividade da página

## 🛠️ Tecnologias Utilizadas

- **[Vite]** - Ferramenta de build
- **[React]** - Biblioteca principal
- **[CSS Modules]** - Estilização responsiva e moderna
- **[Typescript]** - Tipagem
- **[Axios]** - Requisições
- **[Context API]** - Gerenciamento de contexto
- **[Vitest e RTL]** - Testes
- **[Framer Motion]** - Animações
- **[React Router]** - Roteamento

## 🔗 Acesse o Projeto

- https://projeto-valorant-beta.vercel.app/

## 🚀 Como executar localmente

1. Clone o repositório:
`git clone https://github.com/jeancarloslima/projeto-valorant.git`
2. Acesse à pasta do projeto:
`cd projeto-valorant`
3. Instale as dependências:
`npm install`
4. Inicie o ambiente de desenvolvimento:
`npm run dev`
